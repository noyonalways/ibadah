## Requirements
### Requirement: Modernized Hero Visual Layout & Backdrop
The system SHALL render the landing hero with dynamic ambient gradient lighting, refined typography hierarchy, and a pulse-animated feature eyebrow pill.

#### Scenario: Rendering hero ambient lighting and typography
- **WHEN** a visitor loads the home landing page
- **THEN** the hero section displays smooth ambient aura glows, high-contrast headline styling, and an animated status pill.

### Requirement: Interactive Multi-Tab App Preview
The system SHALL present an interactive hero preview component that allows switching between Salah tracking, Dhikr progress, and Quran habits views.

#### Scenario: Switching hero preview tabs
- **WHEN** the user clicks a tab in the hero preview card
- **THEN** the card content transitions smoothly to display the corresponding interactive preview state.

### Requirement: Enhanced Call-To-Action & Trust Signals
The system SHALL render primary and secondary CTA buttons with glowing hover effects, accompanied by trust badges highlighting privacy and free access.

#### Scenario: Interacting with hero CTAs
- **WHEN** hovering or clicking the primary CTA button
- **THEN** the button exhibits a glowing ambient ring transition and directs the user to register/login.

### Requirement: Sleek Metric Cards Bar
The system SHALL render key statistics (Pillars of Islam, Languages supported, Worship logs tracked) inside glassmorphic micro-cards with modern icon accents.

#### Scenario: Displaying hero metrics bar
- **WHEN** viewing the hero section
- **THEN** metric statistics display inside glassmorphic cards with distinct icons and bold typography.
